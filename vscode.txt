from fastapi import FastAPI, File, UploadFile
from fastapi.middleware.cors import CORSMiddleware
from fastapi.responses import JSONResponse
from pydub import AudioSegment
import numpy as np
import librosa
import uvicorn
import joblib
import os

app = FastAPI()

# Allow frontend access
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

# Load model
model = joblib.load("voice_recognition_model.pkl")

# Set threshold for accepting a prediction
CONFIDENCE_THRESHOLD = 0.75

# Extract features from audio
def extract_features(file_path):
    audio, sr = librosa.load(file_path, sr=16000, mono=True)
    mfccs = librosa.feature.mfcc(y=audio, sr=sr, n_mfcc=13)
    return np.mean(mfccs.T, axis=0)

@app.post("/predict")
async def predict(file: UploadFile = File(...)):
    try:
        # Save uploaded file
        with open("temp.webm", "wb") as f:
            f.write(await file.read())

        # Convert to WAV
        sound = AudioSegment.from_file("temp.webm")
        sound.export("temp.wav", format="wav")

        # Extract features
        features = extract_features("temp.wav").reshape(1, -1)

        # Predict and get probabilities
        predicted_class = model.predict(features)[0]
        proba = model.predict_proba(features)
        max_confidence = np.max(proba)

        # Apply threshold
        if max_confidence < CONFIDENCE_THRESHOLD:
            return JSONResponse(content={"prediction": "Unknown", "confidence": round(float(max_confidence), 3)})
        else:
            return JSONResponse(content={"prediction": predicted_class, "confidence": round(float(max_confidence), 3)})

    except Exception as e:
        return JSONResponse(content={"error": str(e)})

    finally:
        for f in ["temp.webm", "temp.wav"]:
            if os.path.exists(f):
                os.remove(f)

# Run: uvicorn server:app --reload --port 5000
if __name__ == "__main__":
    uvicorn.run(app, host="127.0.0.1", port=5000)

      const analyser = audioCtx.createAnalyser();

        let x = 0;

        for (let i = 0; i < bufferLength; i++) {
          const barHeight = dataArray[i] / 1.5;
          canvasCtx.fillStyle = "rgba(255,255,255,0.8)";
          canvasCtx.fillRect(x, canvas.height - barHeight, barWidth, barHeight);
          x += barWidth + 1;

# Voice Authentication System Documentation

## Workflow Overview

This document explains the workflow of the Voice Authentication System, which consists of three main components:
1. Frontend (HTML/JS interface)
2. Backend (FastAPI server)
3. Machine Learning Model (Training and Prediction)

---

## 1. System Architecture

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│             │    │             │    │             │
│  Frontend   │───▶│   Backend   │───▶│  ML Model   │
│ (Browser)   │◀───│ (FastAPI)   │◀───│ (KNN)      │
│             │    │             │    │             │
└─────────────┘    └─────────────┘    └─────────────┘
```

---

## 2. Detailed Workflow

### A. Training Phase (Initial Setup)

1. **Data Collection**
   - Voice samples are collected from users and stored in `voice_samples/` directory
   - Each user has their own subfolder with multiple audio samples

2. **Model Training**
   - Run `train_model.py` script which:
     - Processes each audio file to extract MFCC features
     - Trains a K-Nearest Neighbors classifier
     - Saves the model to `voice_recognition_model.pkl`

3. **Output**
   - Trained model file ready for predictions
   - Labels file for reference

---

### B. Authentication Phase (Daily Operation)

#### Frontend Workflow (index.html)

1. **User Interaction**
   - User visits the web page with modern browser
   - Sees a clean interface with "Start Recording" button

2. **Recording Process**
   - Click "Start Recording" → browser requests microphone access
   - Audio visualization appears on canvas in real-time
   - User speaks their authentication phrase

3. **Stop & Send**
   - Click "Stop & Send" to end recording
   - Audio chunks are combined into a WebM blob

4. **API Communication**
   - Audio sent to backend at `http://127.0.0.1:5000/predict`
   - Displays "Analyzing..." status
   - Shows prediction result or error message

#### Backend Workflow (server.py)

1. **Request Handling**
   - FastAPI receives POST request at `/predict` endpoint
   - Accepts WebM audio file upload

2. **Audio Processing**
   - Saves temporary WebM file
   - Converts to WAV format using pydub
   - Extracts MFCC features using librosa

3. **Prediction**
   - Loads pre-trained KNN model
   - Runs prediction on extracted features
   - Returns predicted user identity

4. **Cleanup**
   - Deletes temporary audio files
   - Returns JSON response to frontend

---

## 3. Key Components

### A. Frontend Features
- Modern UI with gradient background
- Real-time audio visualization
- Responsive buttons with state management
- Error handling and user feedback

### B. Backend Features
- FastAPI for high-performance API
- CORS middleware for cross-origin requests
- Audio conversion (WebM → WAV)
- Feature extraction pipeline

### C. Machine Learning
- MFCC feature extraction (13 coefficients)
- K-Nearest Neighbors classifier
- Model persistence with joblib
- Works with variable-length audio

---

## 4. Setup Instructions

1. **Prerequisites**
   - Python 3.7+
   - Node.js (for development server)
   - Modern web browser

2. **Installation**
   ```bash
   pip install -r requirements.txt
   ```

3. **Running the System**
   - Start backend: `python server.py`
   - Open frontend: `index.html` in browser
   - For training: `python train_model.py`

## 6. Error Handling

| Error Scenario | Resolution |
|----------------|------------|

| Prediction errors | Check audio quality/sample rate |
| Model loading failures | Retrain the model |
